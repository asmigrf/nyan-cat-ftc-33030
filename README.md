# Nyan Cat #33030 — FTC Team Website

Website of the FIRST Tech Challenge team **Nyan Cat #33030** (Almaty, Kazakhstan), season 2026–2027 BIOBUZZ.

Sections: About Us + statistics, Our Team, Upcoming Competitions, BIOBUZZ Score Calculator.

## Files

- `index.html` — the whole site (HTML + CSS + JS in one file)
- `assets/nyan-cat.png` — team cat picture used in the corner and in the falling-cat rain.
  If this file is missing the site still works and shows a 🐱 emoji instead.

## Publishing (GitHub Pages)

Settings → Pages → Source: **Deploy from a branch** → `main` / `(root)` → Save.
The site will be at `https://asmigrf.github.io/nyan-cat-ftc-33030/`.

## Editing

- Statistics: find `No data yet` in `index.html` and replace with real numbers.
- Calculator point values: the `data-pts` attribute on each input.
